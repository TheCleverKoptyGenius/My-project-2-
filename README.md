# Побег из подземелья

# 

# Описание игры

# 

# «Побег из подземелья» — двухмерная игра с видом сверху, выполненная в стиле пиксельной графики на движке Unity.

# 

# Цель игрока — собрать необходимые предметы, избегая врагов, и выбраться из подземелья за ограниченное время.

# 

# Как запустить игру

# 

# Открыть папку DungeonEscape\_Windows.

# 

# Запустить исполняемый файл игры (.exe).

# 

# В главном меню нажать «Начать игру».

# 

# Установка Unity для запуска готовой сборки не требуется.

# 

# Управление

# 

# WASD или стрелки — передвижение персонажа.

# 

# Esc — пауза и продолжение игры.

# 

# Левая кнопка мыши — взаимодействие с кнопками меню.

# 

# Правила игры

# 

# На первом уровне необходимо собрать 5 ключей.

# 

# На втором уровне необходимо собрать 8 кристаллов.

# 

# На прохождение каждого уровня отводится 60 секунд.

# 

# Игрок имеет 3 единицы здоровья.

# 

# При столкновении с врагами игрок получает урон.

# 

# После сбора необходимых предметов открывается дверь.

# 

# После прохождения второго уровня наступает победа.

# 

# При потере всего здоровья или истечении времени наступает поражение.
